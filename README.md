### Featured project · 正在做的项目

| 项目 | 做了什么 | 技术 |
| :--- | :--- | :--- |
| **[🌅 California Sunset](https://github.com/RunWang06/ca-sunset)** | 覆盖加州海岸 58 个观景点，结合多个天气模型，帮助选择观赏地点与时间。[打开预报 →](https://runwang06.github.io/ca-sunset/) | JavaScript · Open-Meteo · GitHub Actions |

**今天／明天哪里值得去、几点到、为什么？** 这是这个项目想回答的三个问题。

它将天气数据、日落时刻与观景点信息放在一起，用地图和推荐列表帮助安排一次看晚霞的小出行。
